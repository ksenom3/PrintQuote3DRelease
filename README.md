> Автоматизирует полный финансовый цикл расчёта 3D-печати: от прямого импорта нарезки из слайсера (`.3mf` Bambu Studio / OrcaSlicer) до честной производственной себестоимости и мгновенной генерации дизайнерской карточки заказа для клиента.

## ⚙️ Инструкция по установке (Важно прочесть)

Так как приложение находится на стадии открытого бета-тестирования и пока не подписано дорогостоящим коммерческим сертификатом разработчика, операционная система может показать стандартное предупреждение защиты:

### Windows (Защитник SmartScreen)
При первом запуске инсталлятора может появиться синее окно: *«Система Windows защитила ваш компьютер»*.
1. Нажмите на текстовую ссылку **«Подробнее»** (More info).
2. Нажмите появившуюся кнопку **«Выполнить в любом случае»** (Run anyway).

---

### macOS (Gatekeeper / Apple Silicon / Intel)
Если при открытии `.dmg` система сообщает, что *«Приложение не может быть открыто, так как разработчик не может быть проверен»* или *«Приложение повреждено»*:

**Способ 1 (через Finder):**
1. Перетащите `PrintQuote 3D` в папку `Программы` (Applications).
2. Нажмите на значок программы **правой кнопкой мыши** (или двумя пальцами по тачпаду) $\to$ выберите **«Открыть»** (Open).
3. В появившемся диалоге подтвердите запуск кнопкой **«Открыть»**. Достаточно сделать это один раз.

**Способ 2 (если macOS всё равно блокирует запуск):**
Откройте встроенную утилиту **Терминал** (Terminal) и выполните одну команду (снимет карантин):
```bash
xattr -cr /Applications/PrintQuote\ 3D.app
```

## 🚀 Ключевые возможности
- **Импорт нарезки из слайсеров**: Мгновенное чтение нарезанных проектов .3mf (Bambu Studio, OrcaSlicer) с извлечением времени, веса и превью столов.
- **Честная себестоимость**: Учёт стоимости филамента, многотарифного электричества (пик/полупик/ночь), амортизации, износа сопел/расходников, резерва на брак и ручного труда мастера.
- **Презентация клиенту в 1 клик**: Автоматическая генерация визуальной PNG-карточки заказа со всеми параметрами для быстрой отправки в мессенджеры.
- **База материалов и Палитра**: Удобный каталог ваших катушек с динамикой закупочных цен и экспортом палитры доступных цветов для заказчиков.
- **Полная приватность**: Все ваши базы, файлы моделей и финансовые настройки хранятся локально на вашем компьютере.
